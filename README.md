# Это сложнее

Evidence-first сайт с короткими интерактивными карточками о мозге, психике, риске и веществах.

## Идея

Каждая карточка строится по схеме:

1. тезис или вопрос;
2. попытка пользователя ответить;
3. краткий разбор;
4. оговорки и границы вывода;
5. источник или тип доказательств.

Цель проекта — не собирать максимальное число «вау-фактов», а показывать, почему научный вывод часто сложнее заголовка.

## Стек

Статический HTML/CSS/JavaScript без сборщика. Это упрощает первый деплой и позволяет сосредоточиться на продукте и контентной модели. Позже проект можно перенести на Next.js, если понадобятся динамические страницы, CMS, поиск и персонализация.

## Важно

Проект образовательный и не заменяет медицинскую помощь, диагностику или персональные рекомендации.
