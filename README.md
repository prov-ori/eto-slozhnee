# Это сложнее

Образовательный сайт о том, как проверять утверждения о риске, исследованиях, мозге и психике.

## Разделы

- **Главная** — короткие факты и вход в «Сегодня»: продолжение урока, карточки к повторению и вопрос дня.
- **Учиться** — стартовый тест из пяти вопросов, рекомендованный маршрут, 9 курсов и тематический практикум. Ссылка вида `learn.html?course=risk-basics&lesson=uncertainty` открывает конкретный урок.
- **Исследовать** — факты, концепты, словарь, книги, атлас, связи, карта знаний и сохранённые материалы.
- **Практика** — упражнения, лаборатории, кейсы и симулятор дизайна исследования.
- **Прогресс** — восемь навыков, очередь повторения и резервная копия. Ссылка на редакционный метод есть в подвале.

## Данные и редактура

- Содержимое курсов, справочника и упражнений лежит в `*-data.js`, `knowledge-courses.js`, `workshop-activities.js` и `bayes-exercises.js`. UI использует общий `ETO_I18N` для выбора языка, локализации и уведомлений о смене языка. `translation-qa.mjs` проверяет наборы переводов RU, EN и ET и ключи в разметке.
- `node generate.mjs` собирает `facts/*.html` и `search-index.json`. Страницы фактов содержат текст, источник, canonical и социальные метаданные в HTML. Старый адрес `fact.html?id=…` ведёт на статическую страницу.
- `material-details.js` отображает дату редакции материала, тип источника, уверенность с пояснением и тематические блоки безопасности. Дата по умолчанию соответствует редакции исходного набора материалов. При изменении отдельного материала укажи его `updated` в ISO-формате. Редакционные уроки и книги показывают пределы оценки без присвоения им уровня доказательности.
- Проверяй, что вывод соответствует дизайну и ограничениям источника. Для эффектов указывай знаменатель, исходный риск и неопределённость. Учебные клинические сценарии не заменяют медицинскую помощь.

## Локальные данные

`learning-core.js` сохраняет данные в `eto-learning-progress-v2` и читает предыдущие версии хранилища, включая заметки практикума. Для каждого навыка учитывается первый ответ на каждое отдельное задание. При наличии минимум трёх разных заданий и доле правильных первых ответов от 75% навык отображается как подтверждённый в упражнениях. Стартовый тест подбирает маршрут и не учитывается в этом показателе.

Экспорт создаёт JSON с прогрессом, заметками, закладками и историей просмотров. Импорт заменяет данные после подтверждения. До 100 записей событий хранятся отдельно в `eto-local-events-v1`. Записи содержат только тип события и день, без поисковых запросов, адресов страниц или идентификаторов. События не экспортируются и не отправляются по сети.

## Проверки

```sh
npm ci
npm test
npx playwright install chromium webkit
npm run test:browser
```

После изменения содержимого, шаблона факта или списка упражнений выполни `npm run generate` и закоммить результаты. GitHub Actions проверяет свежесть сгенерированных файлов, ссылки, локализацию, сохранение прогресса и браузерные сценарии на мобильных Chromium и WebKit и настольном Chromium. Локальный тестовый сервер обслуживает сайт с префиксом GitHub Pages и заголовками CSP из `vercel.json`.

## Путь к Astro

Сайт работает как набор статических страниц и использует обычные переходы по ссылкам. При переходе на Astro сначала перенеси общую разметку шапки, подвала и навигации в `BaseLayout.astro`. Затем перенеси генерацию фактов в статический маршрут с `getStaticPaths()` на основе тех же карточек. Сохрани действующие URL, параметры уроков, относительный префикс сайта, версии хранилища и внешний JavaScript для интерактивов. Прогони текущие тесты против выходного каталога Astro до переключения публикации.
